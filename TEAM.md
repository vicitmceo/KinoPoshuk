# Курсовий проєкт — інформація про команду

**Назва команди:** Kinoposhuk Solo

**Склад команди:**
- Рафаїл — тімлід, розробник (fullstack)

**Розподіл ролей:**
- Рафаїл — аналіз вимог, архітектура, backend (ASP.NET Core), frontend (HTML/CSS/JS), тестування, презентація

**Тема проєкту:** Кінопошук — веб-застосунок пошуку інформації про фільми через OMDb API (рік випуску, постер, рейтинг, тривалість, режисер, актори, опис сюжету).
